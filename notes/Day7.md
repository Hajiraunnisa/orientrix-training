# Bug Reports

## Bug 1: Input text boxes are missing on the "Forgot Account Details" form

**Environment:** Web Browser (Desktop), IRCTC Website
**Severity:** High (Blocks core functionality)

**Steps to Reproduce:**
1. Open the IRCTC website (`https://www.irctc.co.in`).
2. Click on "LOGIN / REGISTER".
3. Click on the "Forgot Account Details" or "Forgot Password" link.
4. Observe the form fields under "FORGOT ACCOUNT DETAILS".

**Expected Result:** 
The user should see visible text input boxes next to the labels for "IRCTC User Name/ Email Id", "Mobile Number", and "Captcha", allowing them to type their details.

**Actual Result:** 
The text input boxes (fields) are completely missing from the UI. Only the text labels are displayed. The user has no area to click or type their email, phone number, or captcha, making it impossible to submit the recovery form.

## Bug Report 2: Image Not Loading on IRCTC Website

**Bug ID:** BUG-002

**Bug Title:** Image Fails to Load on the IRCTC Train Search Page

**Website:** https://www.irctc.co.in/nget/train-search

**Module:** Homepage – Tourism / Package Information Section

**Bug Type:** UI / Image Loading Issue

**Severity:** Low

**Priority:** P3 – Low

**Environment:**
- Browser: Google Chrome
- Operating System: Windows
- Page: IRCTC Train Search Page

### Steps to Reproduce
1. Open the IRCTC website: https://www.irctc.co.in/nget/train-search
2. Scroll down to the tourism and package information section.
3. Locate the package cards displayed on the page.
4. Observe the image area of the card in the second row, third column.
5. Check whether the image loads correctly.

### Expected Result
The image should load successfully and display the appropriate package-related picture, consistent with the other cards on the page.

### Actual Result
The image does not load. A broken image icon is displayed, and the image area appears blank.
